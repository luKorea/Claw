# Claw Logo Kit

Final concept: **Command C**.

## Colors

- Primary: `#044AE9`
- Soft blue: `#EAF2FF`
- Surface blue: `#F4F8FF`
- Ink: `#0B1220`
- Muted: `#44617F`
- White: `#FFFFFF`

## Source Files

- `claw-app-icon.svg`: main app icon source.
- `claw-wordmark-horizontal.svg`: logo + Claw wordmark for light backgrounds.
- `claw-wordmark-white.svg`: logo + Claw wordmark for dark backgrounds.
- `claw-mark-mono.svg`: blue mono mark for light backgrounds.
- `claw-mark-white.svg`: white mono mark for dark backgrounds.
- `claw-ui-mark.svg`: small-size optimized mark for in-app UI, sidebar, and settings dialogs.
- `brand-tokens.json`: brand color and usage metadata.
- `preview.html`: visual preview for final assets.
